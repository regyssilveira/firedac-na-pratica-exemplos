# Projetos por capítulo

Cada diretório de capítulo é autocontido e contém um README com objetivo,
pré-requisitos, compilação, execução, resultado esperado e limitações. Alguns
capítulos concentram seu material na aplicação evolutiva `firestore/`; o Capítulo 4,
por exemplo, é representado pelo marco M0 e suas migrations, provisionamento e
smoke tests.

Os projetos de verificação usam arquivos `.dpr` para permitir compilação explícita e
reprodutível em Win32 e Win64. Consulte o README do capítulo antes de executar o
script correspondente: os laboratórios podem exigir RAD Studio 13, Firebird, uma
biblioteca cliente ou credenciais fornecidas apenas em tempo de execução.
